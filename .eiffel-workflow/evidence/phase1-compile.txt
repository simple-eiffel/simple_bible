   BIB_DATA_SOURCE.open_on ensures provenance_declared (every shipped table declares the column).

4. BIB_BUCKETED_RESULT: four attached bucket lists created together (four_buckets_present,
   total_consistent); `extend'/`seal' exported only to the census and shape engines; extend's frame:
   the three other buckets unchanged (|=|). Census/shape runs: counted_per_hub_id (RQ-12).

6. BIB_AI_TEXT: create {BIB_AI_POST_CHECK}; invariants label_present, cites_engine; post-check

   the facade binds BIB_NULL_AI_ADAPTER.
7. BIB_METHOD invariant scope_stated; BIB_VERSION_INFO invariants never_bare_lxx, kjv_labeled,

## Fixes made to pass the gate (all found by reading logs)

- `reference' is a reserved word: features renamed `ref' (BIB_FINDING, BIB_VERSE_TEXT, BIB_HIT,
  BIB_PARSE_RESULT, BIB_REF_MATCH, BIB_SHAPE_CANDIDATE). Spec 04/05/07 say `reference' (drift note).
- Tags `attached', `unique', `frozen' are keywords: renamed is_attached, unique_id, is_frozen_now.
- `100%' in a manifest string: escaped as 100%%.
- VEEN: missing representation attributes (controls, sections) added.
- VAOL(2): `old' over an across-local in BIB_BUCKETED_RESULT.extend; replaced by
  `other_buckets_model (v) |=| old other_buckets_model (v)'.
- VAPE: secret features in preconditions (census set_criteria; SIMPLE_BIBLE.attach_private_source)
  replaced by exported queries (has_control_named_by, can_attach_private_source).
- Obsolete Call (DIRECTORY.linear_representation) in SOURCE_SCAN: replaced by `entries'.

## Gaps (fleet work items; nothing hacked around)

- GAP-EC-01 (ec.sh): `run_ec' pipes ec.exe into `tee' and reads `$?', which is tee's status, so
  every mode reports success and "passed" regardless of compiler errors. Fix: use
  ${PIPESTATUS[0]} (or set -o pipefail) and grep the log for "Error code"/"Syntax error"/"Warning:"
  before printing the summary. Also: obsolete calls are reported under "Error code: Obsolete Call"
  with a "Warning:" line, so counting only "Warning code" misses them.
- LG-01 (simple_encoding): the normalizers are written against the deferred BIB_UNICODE_SERVICE seam;
  SIMPLE_BIBLE.normalizers (and so `search' and `divine_names') stays a Phase-4 stub until the
  simple_encoding adapter exists. AC-1a-20/21/23 tests are skeletal until then.
- FT-01/FT-02 (eiffel_sqlite_2025): SQLite 3.31.1; c_sqlite3_step/open_v2/close not `blocking'.
  Noted in BIB_SOURCE_SET; not patched here. Gates AC-1a-48 (app) and every worker-processor query.
- LG-09 (simple_hash 8-bit paths): noted in BIB_MARKDOWN_NOTE_STORE (file_hash).
- LG-03 (simple_sql STRING_32 accessors): banned accessors absent (static test enforces).

## Design notes for /eiffel.review (departures from 04/05/07, each deliberate)

1. BIB_SOURCED (new deferred class) is how RQ-02 is met: every result item is a BIB_SOURCED,
   BIB_LIST_RESULT [G -> BIB_SOURCED], so plain values travel as BIB_FACT [G].
2. BIB_LICENSE_GATE lives in the engine over BIB_LICENSED_ITEM; bible_build's BIB_PINNED_SOURCE should
   inherit BIB_LICENSED_ITEM, and check_items replaces check_manifest (the manifest is a build class).
3. BIB_BUCKETED_RESULT.extend/seal exported to {BIB_CENSUS_ENGINE, BIB_SHAPE_ENGINE} only (the build's
   BIB_SHAPE_PRECOMPUTE calls BIB_SHAPE_ENGINE.run; the engine names no build class).
4. RQ-01 layering: the facade names no user-cluster type; BIB_CENSUS_JOB does not store runs (the face
   stores them through BIB_USER_STORE); BIB_PLUGIN has no `commands' (a CLI type; it moves to an
   app-level extension in simple_bible_app.ecf).
5. SCOOP: a precondition on a separate argument is a WAIT condition, so the mailbox's page-order rule
   is a postcondition (`in_order'), not a precondition; BIB_JOB_WAITER uses wait conditions on purpose
   (no polling). SIMPLE_BIBLE.make_from_separate copies plain configuration values; plug-ins are not
   copied across processors (the private root must register per processor - open question).
6. BIB_AI_POST_CHECK detectors answer True (withhold) until v3: fail safe.
7. BIB_CONTROL_SET.make_frequency_matched keeps 05's `deterministic' self-re-creation clause (test
   oracle); review decides whether it becomes debug-only.
8. BIB_GUIDE: "no empty section" is a precondition of creation and add_section, not an invariant (C-019).
9. BIB_VERSE_RESULT for ambiguous text is a failed answer (error Ambiguous_reference) carrying the
   candidates, never a guess.
