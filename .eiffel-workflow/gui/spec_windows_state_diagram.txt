simple_bible GUI - state diagrams (ASCII)
2026-10-06. Source: spec_windows.json (root "states"/"transitions" and "state_machines").
Widget vocabulary: simple_widgets 0.8.1 (SW_* classes), a deliberate deviation from the
eiffel-gui-ux skill's simple_vision "windows" platform (D-006).

The app runs three orthogonal regions at once. simple_spec_viz draws them in one
state_machine.svg; its single start dot feeds the initial state of each region.

Notation:  [state]   --event [guard] / action-->   (*) initial   (@) final

======================================================================================
DIALOG MACHINES (in "state_machines" only; not drawn by simple_spec_viz)
======================================================================================

 go_to_flow (D01, reference box)
   (*)[typing] --text_changed [valid]-------> [parsed_valid] --submit / raise go_to--> [typing]
   [typing]    --text_changed [ambiguous]---> [parsed_ambiguous] --candidate_chosen / raise go_to--> [typing]
   [typing]    --submit [invalid]-----------> [parsed_invalid] --text_changed--> [typing]

 census_flow (D03, FR-025)
   (*)[draft] --field_changed [complete]--> [complete] --save--> [stored] --run / freeze--> (@)[locked]
   [complete] --field_cleared--> [draft]
   [complete] --run / store and freeze--> (@)[locked]
   locked = read-only; any edit creates a new definition version.

 export_flow (D06)
   (*)[choosing] --options_changed--> [previewing] (options_changed: self)
   [previewing] --copy_or_save [target valid]--> [writing] --written--> (@)[done]
   [writing] --write_failed / show error--> [previewing]
